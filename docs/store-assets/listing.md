# 누가할래 앱인토스 등록 문구

## 앱 이름

- 영문: **Who Is Up?** (확정. 앱인토스 이름 정책 때문에 `Who's Up?` 대신 이 표기를 써요)
- appName(변경 불가): `nugahallae`

## 부제 (확정)
- **재밌고 간단하게 당번 뽑기**

## 상세 설명
누가 할지 정할 때 가위바위보 대신, 폰 하나를 돌려 가며 미니게임으로 정해요.
로그인이나 입력할 것이 없어서 열자마자 시작할 수 있어요.

이렇게 사용해요
1. 홈에서 하고 싶은 게임을 골라요. 돌림판, 사다리 타기, 잔 채우기, 라이어 게임 등 30가지가 있고, 위쪽 검색창으로 이름을 찾을 수도 있어요.
2. 함께하는 인원수를 정해요. 2명부터 10명까지 고를 수 있어요.
3. 동물 카드가 한꺼번에 나타나요. 한 사람씩 돌아가며 마음에 드는 동물을 하나 골라 기억해요. 고른 순서가 게임의 차례예요.
4. 게임을 시작해요. 돌림판은 화살표가 가리킨 동물이 통과하고, 마지막까지 남은 동물이 걸려요. 잔 채우기는 꾹 눌러 물을 붓다가 넘치게 하면 걸려요. 게임마다 규칙이 화면 위에 한 줄로 나와요.
5. 게임이 끝나면 결과가 바로 나타나요. 기다리는 연출 없이 걸린 동물이 크게 보이고, 같은 게임을 한 판 더 하거나 다른 게임을 고를 수 있어요.

이런 게임이 있어요
- 차례대로 하는 게임: 돌림판, 사다리 타기, 폭탄 돌리기
- 기록으로 겨루는 게임: 잔 채우기, 타이머 멈추기, 반응속도
- 비밀을 돌려 보는 게임: 라이어 게임, 제시어 확인

가볍게 즐기는 당번 정하기, 설거지 순서, 간식 심부름처럼 일상의 작은 선택에 써 보세요.

## 확인 메모
- 상세 설명에는 확인된 기능만 썼어요(게임 30개, 인원 2~10명, 로그인 없음, 즉시 결과).
- 심사에서 '내기·당첨·돈' 같은 표현은 피했어요. 새 문구를 넣을 때도 같은 기준을 지켜 주세요.
- 카테고리는 비게임으로 등록하는 것으로 정했어요. 심사에서 게임으로 분류될 수 있으니 안내가 오면 확인하세요.
