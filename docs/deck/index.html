테스트가 못 잡은 버그

어디서 찾았나

실제 브라우저에서 375px 폭으로 열어 봤을 때. 전선 자르기 게임의 2열 목록이 화면 밖으로 넘쳤어요.

무엇이 놓쳤나

단위 테스트와 코드 리뷰가 모두 통과했어요.

원인

CSS의 1fr은 최소 폭이 내용 크기라서, 안의 그림이 칸을 밀어 냈어요.

고친 방법

7곳을 minmax(0, 1fr)로 바꾸고, 맨 1fr을 쓰면 실패하는 검사 테스트를 남겼어요.
